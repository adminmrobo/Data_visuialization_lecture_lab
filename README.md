# 데이터시각화 (Data Visualization) — 통합 강의 저장소

생성형 AI와 함께 배우는 데이터 시각화. 2026학년도 2학기 데이터사이언스전공 「데이터시각화」 강의 자료를 주차별 폴더로 모은 통합 저장소입니다.

바로 보기: https://adminmrobo.github.io/Data_visuialization_lecture_lab/

글 · 안상선 ((주)M-Robo 대표)

## 이력

1~4주차는 원래 `Data_visuialization_lecture_01` ~ `_04` 개별 저장소로 운영하다가 이 저장소로 통합했습니다. 각 저장소의 커밋 기록은 `lecture_NN/` 폴더 아래에 그대로 보존되어 있습니다.
